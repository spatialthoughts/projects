## Data Visualization

This folder contains web maps and dashboards built with open-source JavaScript libraries.

### Dashboards

- [`highway_dashboard`](https://github.com/spatialthoughts/projects/tree/master/dataviz/highway_dashboard): Interactive dashboard of National Highway (NH) and State Highway (SH) lengths by district in Karnataka, built with MapLibre, OpenFreeMap and Observable Plot. `prepare_data.py` converts the source GeoPackage and CSV into the `data/data.js` file loaded by `index.html`.
