# projects

A collection of geospatial scripts, notebooks and workflows.

- [`python`](https://github.com/spatialthoughts/projects/tree/master/python): Geospatial Python scripts and notebooks for data processing, Pandas, GeoPandas, Xarray, visualization and APIs.
- [`ee-python`](https://github.com/spatialthoughts/projects/tree/master/ee-python): Google Earth Engine Python API scripts and notebooks.
- [`dataviz`](https://github.com/spatialthoughts/projects/tree/master/dataviz): Web maps and dashboards built with MapLibre and Observable Plot.
- [`pyqgis`](https://github.com/spatialthoughts/projects/tree/master/pyqgis): Useful PyQGIS scripts.
- [`imd`](https://github.com/spatialthoughts/projects/tree/master/imd): Processing IMD (Indian Meteorological Department) gridded rainfall data.
- [`geeup`](https://github.com/spatialthoughts/projects/tree/master/geeup): Scripts for uploading data to Google Earth Engine using geeup.
- [`fill_nodata`](https://github.com/spatialthoughts/projects/tree/master/fill_nodata): Filling missing rows of data in aerial imagery.
